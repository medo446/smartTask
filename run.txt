how to run it

Open PowerShell in the project folder and run:

npm install
npm run dev

Then open the local address Vite prints, usually http://localhost:5173.

To run the tests:

npm test

For Selenium, leave the app running in one terminal, then open a second PowerShell window in the project folder and run:

npm run test:e2e

Chrome needs to be installed for the Selenium test.
